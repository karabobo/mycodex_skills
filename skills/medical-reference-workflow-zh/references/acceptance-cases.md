# 合成验收案例

以下均为虚构材料；用于核验决策，不作为医学证据。修改规则后逐案检查实际输出的命题/证据/覆盖表及高亮位置，不以复述规则算通过。

| 输入 | 必须观察到的行为 | 失败信号 |
|---|---|---|
| 原句“第12天激活并扩增效应T细胞”；引言引述既往第12天增殖标志物，正文第28天测TCR和基因签名 | 拆时间点/指标，标转述来源；原句部分支持，不能以第28天结果支持第12天全句 | 一个supported覆盖整句；只标摘要 |
| 原句“唯一方案，4年OS 21%”；表格确有指定人群21%，无唯一性检索 | 数字子命题可支持并高亮；唯一性单列未证实。closest模式也不升级判定 | 因唯一性不成立而整篇不标，或整句标支持 |
| 用户要求最贴近、无批注；证据来自另一疾病、剂量不同 | 标相关观察及疾病/剂量限定，外部记录source_mismatch，PDF无文字评论 | 自动切回只支持模式；把最贴近改成supported；加便签 |
| 表中A组n40、ORR12/40、含未确认应答；B组及页脚也出现相同数字 | 标A组表头、分母、结果与限定，按区域命中 | 标错列、涂全表、孤立数字、误标页脚 |
| 研究结论“仅随访留组者平均指标稳定”；原句“保障后续治疗” | 标观察及留组限定，保障性因果单列无支持 | 删掉留组限定；把均值稳定当个体保护 |
| DOI对应8页论文，输入为2页摘要网页PDF；另有XML | 类型为摘要打印/结构化全文，正式PDF缺口仍在；转换件另标 | 将有效PDF或XML转换件称出版全文 |
| 地区A标签术语不同于地区B，生效日期不同 | 保留地区/版本/原词，针对目标地区核对并解释冲突 | 凭另一地区标签判目标术语错误 |
| 增量替换一篇、复用另一篇；用户改过旧输出；新增说明书无引用编号 | 检测哈希变化并保留；稳定ID回并映射/覆盖/计数；不虚构编号 | 覆盖用户改动；专项数加旧总数；旧索引仍称缺文件 |
