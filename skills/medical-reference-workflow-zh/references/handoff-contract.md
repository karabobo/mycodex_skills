# 文献流程交接契约

仅在组合多个阶段时使用。保留现有清单的列与行顺序；可增加映射列或附表，不为套用本契约而重写旧表。

## 身份

- **文献 ID（work ID）：**对应一篇被引作品或一个独立版本，贯穿题录、EndNote、联网来源、求助和 PDF 核验。
- **引用出现 ID（occurrence ID）：**对应 PPT 某一页的一次引用，关联文献 ID，保留页码、页面原话和角标/位置。多次引用可指向同一文献 ID。
- **论断 ID（claim ID）：**对应一条可核验的页面表述，关联页码、引用出现记录与被引文献。复合表述可拆成多个论断 ID。

不能仅凭作者或主题相似就合并会议摘要、正式论文、补充材料或指南更新版。身份不明时保留暂定关系及竞争候选。

## 阶段字段

分别记录 `metadata_status`、`endnote_status`、`online_status`、`pdf_status`、`claim_verdict`，不能用一个“完成”状态代替五种状态。PPT 上印出的 DOI、标题保留在原始字段；题录核实后才写入已确认字段。归档 PDF 记录来源类别、稳定落地页、版本、文件路径、页数和 SHA-256。多个来源的尝试可单列日志，用文献 ID 关联；不保存凭据、Cookie 或临时下载链接。

现有的一行一条引文 CSV，可用原“编号”作为引用出现 ID，再增加或映射稳定的文献 ID；重复引文也不丢弃原有列。若用户要求全新结构，文献表与引用出现表分开，比每页重复抄写题录更清晰。

## 完成核对

分别核对 PPT 引用次数、独立文献数、题录已核实数、各来源 PDF 数、未解决文献数、各类论断判断数及高亮副本数。每项未完成记录原因与下一途径。有 PDF 不等于论断获支持；高亮须在论断台账中对应到原文位置和限定语。
